# CampusMarket

CampusMarket is a database-driven e-commerce web application being developed incrementally for CS 2314: Web Based Programming II.

## Current stage

Weeks 1-3 foundation:

- HTML5 semantic structure
- CSS3 responsive styling
- JavaScript catalog filtering
- Live quantity calculations
- Registration form
- Client-side validation
- Interactive password show/hide control
- Live validation feedback

## Files

- `index.html` — home page
- `catalog.html` — product catalog
- `register.html` — registration form
- `styles.css` — shared styling
- `app.js` — JavaScript behavior

## Run locally

Open `index.html` in a browser, or serve the folder with a local development server.

No PHP/MySQL functionality is included yet because those are later stages of the semester project.
