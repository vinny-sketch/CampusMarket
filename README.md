## About the Project

CampusMarket is a university marketplace web application developed incrementally for the CS 2314 Web Based Programming II coursework at Multimedia University of Kenya.

The project provides a student-focused shopping experience where users can browse campus essentials, filter products, view a responsive product gallery, manage quantities, add products to a cart, and submit their registration interest.

## Features

- Responsive CampusMarket homepage
- Product catalog with category filtering
- Product search
- Filtered product gallery/slideshow
- Gallery navigation with wraparound
- Product quantity validation
- Running purchase total
- Shopping cart with quantity controls
- Cart subtotal calculation
- Registration form validation
- Specific validation error messages
- CSS transitions for validation feedback
- CSS keyframe animation for successful registration
- Meaningful image alt text
- Responsive layout for smaller screens

## Week 4 Requirements

The Week 4 implementation builds on the previous weeks by adding:

1. Filtered catalog results reflected in the product gallery.
2. A running total based only on validated quantities.
3. Successful form submission with a CSS keyframe animation triggered through JavaScript.
4. Specific validation messages for invalid form input.
5. CSS transition feedback for validation states.
6. Meaningful alternative text for product images.
