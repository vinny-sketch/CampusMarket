# CampusMarket

CampusMarket is a university marketplace project developed as part of the CS 2314 Web Based Programming II coursework at Multimedia University of Kenya.

## Current Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Lucide React
* Motion
* Express
* Google GenAI SDK

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The Vite development server runs on port `3000`.

## Build

Create a production build:

```bash
npm run build
```

## Type Checking

Run TypeScript checking with:

```bash
npm run lint
```
